C — Key handling rules (what “never revealed” means in code)

SrNo.SurfaceRule
1ScreenStatus only (SET / NOT SET / IN APP); input masked while typing; no eye icon; no suffix
2StorageEncrypted prefs (self-healing, PinStore pattern); excluded from Auto Backup and from every export/share/JSON
3Logs / errors“API key added/removed” lines only; HTTP errors logged with the key parameter stripped from URLs
4WritesAdd new → Confirm 1 + typed SAVE · Remove → Confirm 1 + typed Remove · no Change (remove, then add)
