Rules

SrNo.RuleBehaviour
1AppearsOn a shop geofence ENTER that has pending items — even if the alert itself is muted (the view is not the alert).
2ContentActive items whose shop = the triggering shop (by shopId, falling back to shop name). Never Done items.
3TapCompletes → Done (checkout calculator first if enabled), Undo available.
4ReplaceA newer trigger overwrites the shop; only one Buy Now ever exists.
5HideOnly by the Hide ✕ (or the Buy Now segment’s long-press). Survives app restarts and reboots until hidden.
6Personal itemsStay locked; shown as the 🔒 row until unlocked, exactly as in Active.
7DataUiStore (view state, per device, not synced): buyNowShopId, buyNowAt. No schema change.
