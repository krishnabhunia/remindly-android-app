D — Provider resolution (the rule the app follows on every map open / address lookup)

Provider = Google?
→
Not locked this month?
→
Key present?
→
Play Services OK?
→
Count < limit?
→
Use Google (count +1 for geocoding)
Any “no” → use OSM for this call
·
Google quota error (429 / OVER_QUERY_LIMIT / REQUEST_DENIED) → use OSM AND lock until the 1st
·
Timeout / network error → OSM for this call only (no lock)
Two guards, always: (1) this app-side counter + lock; (2) your Cloud Console quota cap on the Geocoding API. Map loads (Maps SDK) are unlimited and never counted. Everything Google-side is logged to Error Logs when it falls back.
